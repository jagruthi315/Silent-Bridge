# 🤝 SilentBridge

An AI-powered communication system designed to bridge the gap between
individuals who use sign language and those who communicate through speech.

## 💡 What It Does
- Detects hand gestures in real time using a webcam
- Converts speech to clean readable text
- Uses AI to generate smart, context-aware chat replies
- Brings everything together in a live web interface

## 🛠️ Tech Stack
Python · OpenCV · MediaPipe · TensorFlow · Whisper · Flask · Scikit-learn
